# PrimeReact Components Showcase

Proyecto para la de demostración de componentes PrimeReact,  replica la estructura de la documentación oficial de PrimeReact.

## Componentes Incluidos

El menú lateral incluye las siguientes categorías de componentes:

- **FORM** - Componentes de formulario (InputText, Dropdown, Calendar, etc.)
- **BUTTON** - Variaciones de botones y acciones
- **DATA** - Componentes para manejo de datos (DataTable, TreeTable, etc.)
- **PANEL** - Componentes de paneles y contenedores
- **OVERLAY** - Modales, tooltips y overlays
- **FILE** - Componentes para manejo de archivos
- **MENU** - Diferentes tipos de menús y navegación
- **MESSAGES** - Componentes de mensajes y notificaciones
- **MEDIA** - Componentes multimedia (Image, Galleria, etc.)
- **MISC** - Componentes misceláneos
- **NEW** - Componentes nuevos creados por el equipo UX/UI

## Requisitos Previos

Asegúrate de tener instalado:

- **Node.js**:  v20.18.3 o superior
- **npm**: v10.8.2

## Tecnologías Utilizadas

| Tecnología | Versión | Descripción |
|------------|---------|-------------|
| **React** | ^18.2.0 | Librería principal para la interfaz de usuario |
| **PrimeReact** | ^10.8.2 | Librería de componentes UI rica y completa |
| **Tailwindcss-primeui** | ^0.6.1 | Libreria de estilos |
| **Tailwindcss** | ^3.4.17 | Libreria de estilos |
| **TypeScript** | ^5| Tipado estático para JavaScript (opcional) |

## Instalación y Configuración

### 1. Clonar el repositorio
```bash
git clone https://github.com/AdamaryMargell/boilertemplate_react.git
cd boilerplate-react
```
### 2. Instalar dependencias
```bash
npm install
```
### 3. Iniciar el servidor de desarrollo
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
### 4. Explorar el proyecto
Abre en [http://localhost:3000](http://localhost:3000) para ver el resultado y Abre el menú lateral haciendo clic en el ícono de hamburguesa (☰)
Explora las categorías de componentes organizadas como en la documentación de PrimeReact
